# 熊酒馆 · 在线桌面冒险

玩家入口：https://ghostbear111.github.io/BearTRPG-Play/

这是独立的静态游玩网站，包含《星海群侠传 · 桌面 RPG》的剧情、规则和所引用的 65 份模型、图片及音频资源。玩家打开链接即可游玩，无需进入编辑模式。

## 纯净桌游编辑器

编辑器入口：https://ghostbear111.github.io/BearTRPG-Play/editor/

此入口来自 BearTRPG 纯净编辑器，不预装《星海群侠传》。支持自定义物件、角色卡、文字 APNG、故事创作、模组导入导出以及编辑后试玩；模板、图片与作品保存在当前浏览器。原源码仓库保持私有，本公开仓库只部署网站构建产物。在线编辑器不包含 AI 代理或云存储。

## 游玩

- W/A/S/D 或方向键移动队长，空格交互。
- 在星图选择目的地，探索事件、战斗、学习武功、管理装备与队伍。
- 进度自动保存在当前浏览器；“跑团存档”支持继续、新建、命名与删除。
- 右上角可下载进度备份；在跑团存档中可导入同一版本的备份。
- 第一次进入需要下载场景与角色模型，请等待资源加载；浏览器需要支持 WebGL。

这个版本不提供多人实时同步、云端存档或服务器 AI 主持。不同设备的进度互相独立。GitHub Pages 提供静态文件，API 密钥和本机数据库不在发布包内。

## 部署和更新

仓库中的 `site/` 是可直接部署的完整产物，`.github/workflows/pages.yml` 在 `main` 分支更新后自动部署 GitHub Pages。仓库 Settings → Pages 的部署源应选择 GitHub Actions。

在熊酒馆编辑器源项目中运行 `npm run build:pages` 可重新生成 `artifacts/pages-site/`；将其内容更新到此仓库 `site/` 后提交。只复制生成的网站，勿上传本机 `data/`、`.env`、玩家进度或连接凭据。

发布时只收集所选游戏声明的资源，以内容哈希命名。相同内容保持相同游玩链接；修改游戏内容或资源后生成新版本链接，并独立保留存档，避免用旧进度覆盖新的游戏规则。

原 BearTRPG 仓库保留纯净桌游编辑器。本仓库只发布游玩网站，不修改它。

## 资源信息

游戏中的资源署名与来源信息保留在 `site/published/<版本>/game.json` 中。资源包只包括游戏实际引用的内容，并非原项目全部模型库。
